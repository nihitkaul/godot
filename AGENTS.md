# Repository continuity

Read [AGENT_HANDOFF.md](AGENT_HANDOFF.md) and the project README before changes. Follow any more specific instructions in subdirectories.

Keep this repository ready for the next agent: document architecture/component responsibilities, runtime and service connections, prerequisites, exact setup/run/test commands, configuration variable names (never secrets), persistence, deployment, troubleshooting and current limitations. Update this context when behavior changes. Run relevant checks, commit reviewed changes and push authorized work, then verify the remote result. Preserve existing visibility and unrelated work. Never commit credentials, private runtime data, browser profiles or generated dependencies. Distinguish checks actually run from commands merely documented.
